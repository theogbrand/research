# Research Repository

This repository stores small AI-generated projects, with each project organized in its own directory separated by project name.

## Structure

Each project is contained within its own directory:

```
/
├── project-name-1/
├── project-name-2/
├── project-name-3/
└── ...
```

## Purpose

This is a workspace for experimenting with and storing various AI-generated code projects, prototypes, and research initiatives.
